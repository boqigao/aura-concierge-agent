# Agents-CLI Project Specification: Aura Executive Personal Concierge Agent

## Overview
- **Project Name**: `aura-concierge-agent`
- **Framework**: Google Agent Development Kit (ADK) Python
- **Track**: Concierge Agents (Finance Management, Health & Wellness Management, Schedule & Calendar Management)
- **Deployment Target**: Cloud Run / Vertex AI Agent Engine (`agents-cli deploy`)
- **Infrastructure Provisioning**: Terraform (`terraform/main.tf`) + `agents-cli`

## Architecture & Multi-Agent Topology
1. **`executive_concierge_coordinator` (`gemini-2.5-pro`)**: Root Coordinator agent responsible for cross-domain planning, intent classification, policy compliance, and delegating to specialized sub-agents.
2. **`finance_wealth_specialist_agent` (`gemini-2.5-pro`)**: Handles complex quantitative cashflow variance analysis, tax-advantaged portfolio optimization, and high-value wire transfers (protected by Human-in-the-Loop approval hooks).
3. **`health_wellness_telemetry_agent` (`gemini-2.5-flash`)**: Low-latency biometric telemetry logging, cardiovascular readiness scoring, and personalized nutrition protocols.
4. **`schedule_calendar_orchestrator_agent` (`gemini-2.5-flash`)**: Conflict-aware executive meeting scheduling, deep-work focus block allocation, and automated overlap resolution.
5. **`morning_executive_briefing_pipeline` (`SequentialAgent` + `ParallelAgent`)**: Parallel data gathering across Finance, Health, and Schedule domains followed by sequential synthesis into a unified daily briefing.
